# ShortScroll APK
1. Create a new GitHub repo and upload everything in this folder (keep .github/workflows).
2. Open the Actions tab -> "Build APK" -> wait for green -> download artifact "ShortScroll-debug-apk".
3. Unzip it, install app-debug.apk on your phone (allow "install unknown apps").
Use: tap the "Auto-scroll" pill to toggle. Long-press it to raise the delay (0-10s). The top-bar menu (three dots) switches site.
